# المعمارية

فلاي فان مستودع واحد (monorepo) ومنصة معيارية، لا خدمات مصغّرة.

## التطبيقات

- `apps/web`: Next.js وApp Router. الواجهة عربية واتجاهها من اليمين لليسار. الحجوزات والرحلات والسائقون والمالية مربوطة بالواجهة البرمجية. سجل التدقيق ما زال بلا استعلام تفصيلي.
- `apps/api`: NestJS. المسار العام `/api`. الوثائق على `/api/docs`. المصادقة والتشغيل والدفتر المالي مفعّلة.
- `apps/mobile`: Expo لتطبيق السائق. الدخول والملف ومناطق الخدمة وقبول العروض ومسار الرحلة ورصيد العمولة تُقرأ من الخادم.

## الحزم

- `packages/database`: مخطط Prisma 7 وعميل PostgreSQL وبذر التطوير.
- `packages/types`: كتالوج الصلاحيات، تقريب العمولة، رقم الحجز، وواجهة مزود المسارات.
- `packages/ui`: ألوان الهوية ومكونات الأزرار والحقول والبطاقات والجداول والنوافذ والحالات.
- `packages/config`: TypeScript وESLint المشتركان.

## البيانات والتكاملات

PostgreSQL هو مصدر الحقيقة للبيانات المالية والتشغيلية. Redis غير مستخدم لأنه لا توجد مهام خلفية.

منطق المطابقة لا يتصل بمزود خرائط مباشرة. مسار الرحلة يمر عبر `RouteProvider`. عند `ROUTE_OSRM_URL=off` يبقى `UnconfiguredRouteProvider` ويرفض التقدير ولا يخترع مسافة.

المصادقة والوحدات التشغيلية تُضاف فوق هذا الأساس في المراحل التالية. لا توجد نقاط نهاية شكلية تعيد نجاحًا لعمليات لم تُبنَ.
