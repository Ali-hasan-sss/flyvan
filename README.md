# Fly Van — فلاي فان

منصة تنسيق نقل الركاب، وخصوصًا الطلاب، من نقاط الالتقاط إلى الجامعات أو الوجهات المحددة. الشركة هي الجهة المركزية، والسائق يتعاقد معها مباشرة.

هذه النسخة تكمل المراحل 0 إلى 6: هيكل المستودع، والمصادقة، والسائقين والمناطق، والحجوزات والرحلات، ودفتر العمولة، ثم تطبيق السائق مربوطًا بالعروض ومسار الرحلة والرصيد.

القواعد الملزمة في `.cursor/rules/permissions.mdc`. الافتراضات المعلّقة في `docs/assumptions.md`.

## المتطلبات

- Node.js 22 أو أحدث (جرى التحقق على 24.13.1)
- pnpm 10
- Docker مع Docker Compose

## التشغيل المحلي

```powershell
Copy-Item .env.example .env
docker compose up -d
pnpm install
pnpm db:migrate
pnpm --filter @flyvan/api dev
pnpm --filter @flyvan/web dev
```

في طرفية أخرى للواجهة البرمجية والويب كما في الأمرين الأخيرين. الويب على `http://localhost:3000` والواجهة البرمجية على `http://localhost:3001/api/health` ووثائقها على `http://localhost:3001/api/docs`.

تطبيق السائق:

```powershell
pnpm --filter @flyvan/mobile start
```

`EXPO_PUBLIC_API_URL` يشير افتراضيًا إلى `localhost`، وهذا يناسب المحاكي على الجهاز نفسه لا الهاتف الفعلي.

قاعدة التطوير تُنشر على المنفذ `5434` لأن `5432` و`5433` مستخدمان من مشاريع محلية أخرى. كلمة مرور PostgreSQL في `docker-compose.yml` للتطوير المحلي فقط، ولا تُستخدم في أي بيئة مشتركة أو إنتاجية.

## بذر التطوير

البذر لا يعمل في `NODE_ENV=production`، ولا يعمل إلا إذا كان `SEED_ENABLED=true`. ضع في `.env` بريدًا محليًا وكلمة مرور لا تقل عن 8 أحرف، ثم:

```powershell
pnpm db:seed
```

إذا كان المستخدم موجودًا تبقى كلمة مروره كما هي. اترك `SEED_DEFAULT_COMMISSION_RATE` فارغًا إذا لم ترد إنشاء سياسة عمولة تطويرية. لا تضع كلمة المرور في Git.

البذر ينشئ مالك منصة للتطوير، ومدير عمليات إذا زُوّد بريده وكلمة مروره، وكتالوج الصلاحيات فقط. لا ينشئ سائقين أو ركابًا أو رحلات.

## ما لم يُنفَّذ

تقارير المتأخرات التفصيلية، وعكس العمولة عند النزاع، وتوسيع سجل التدقيق. زر الاستغاثة غير مفعّل. لا دفع إلكتروني ولا اشتراك شهري ولا مكاتب تاكسي.
